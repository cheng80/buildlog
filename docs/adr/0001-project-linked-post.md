# 사용자 게시물은 하나의 프로젝트에 귀속한다

빌드로그의 차별점은 짧은 개발 게시물이 프로젝트의 지속적인 이력으로 남는 데 있다. 자유로운 일상 게시와 느슨한 프로젝트 태그 방식 대신, 사용자 게시물을 정확히 하나의 프로젝트에 연결하고 피드와 프로젝트 타임라인에서 같은 게시물을 보여주는 기존 결정을 보존한다. 연결을 선택 사항으로 바꾸면 작성·탐색·권한·기록의 의미가 함께 달라지므로 명시적인 재검토가 필요하다.

`accepted`는 핸드오프가 전달한 기존 결정을 기록한 것이며, 이번 문답에서 새로 승인받았다는 뜻은 아니다. 프로젝트에 귀속되지 않는 공식 카드에는 이 제약을 적용하지 않는다. [제품 명세 BR-001/BR-002](../01_PRODUCT_SPEC.md#7-공통-비즈니스-규칙)
