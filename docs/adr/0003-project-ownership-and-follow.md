# MVP의 관리와 팔로우를 프로젝트 단위로 제한한다

소규모 팀도 대상이지만 MVP에서는 프로젝트를 한 계정이 관리하고 팀명은 소개 정보로 표시한다. 사용자가 Q2에서 이 범위를 선택했으므로 멤버 초대·공동 편집·소유권 이전은 이후로 두며, 계정 공유로 이를 대신하지 않는다.

Q3에 따라 방문자는 개발자 대신 프로젝트를 팔로우하고 팔로잉 피드에서 새 게시물을 확인한다. 좋아요·비공개 저장은 포함하되 댓글·별도 알림함은 이후로 두고 기본 카드의 반응 숫자는 숨긴다. 이 경계는 소유권·쓰기 권한과 팔로우 관계의 대상을 바꾸므로, 이후 팀 기능이나 개발자 팔로우를 추가할 때 명시적으로 재검토한다. [제품 명세](../01_PRODUCT_SPEC.md), [결정 기록](../plans/PLAN-001-planning-review.md)
