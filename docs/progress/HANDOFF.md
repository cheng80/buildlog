## 반드시 보존할 내용

- 프로젝트와 연결된 게시물 하나가 피드와 타임라인에 함께 나타난다.
- 새 게시에 따른 자연 재노출과 유료 노출은 구분한다.
- 개발 기간은 최대 40일이다. 일별 작업 배정·고정 순서·40회 변경을 요구하지 않으며, 완료한 작업을 특정 날짜까지 기다리게 하지 않는다.
- 공식/데모는 명시하며 가짜 반응·사용자 수·가격을 만들지 않는다.
- Kakao 지도는 선택 입력·기본 비공개이며 시군구/지역 중심만 공개한다. 정확한 주소는 수집하지 않는다.
- Featured는 Toss 테스트 1,000원·7일이다. 결제 후 사용자가 시작하고 시작 전 전액 취소할 수 있다. 시작 후 사용자 취소는 막고 미제공·서비스 오류는 운영자 전액 취소로 처리한다. 실판매 가격이 아니다.
- 사용자 삭제·탈퇴는 즉시 공개 종료 후 30일 뒤 원문/파일을 정리한다. 진행 거래는 먼저 취소·종료한다. 운영자 숨김을 30일 자동 삭제로 처리하거나 사용자 복구 기능을 약속하지 않는다.
- 외부 수집 콘텐츠는 출처가 있는 소식 카드이며 빌드로그 가입자·사용자 게시물로 가장하지 않는다. AI 출력과 포럼 원문은 검증할 자료다.
- ADR은 `docs/adr/`, 용어는 루트 `CONTEXT.md`, 구현 이슈는 기존 `.scratch` 규칙을 따른다.
