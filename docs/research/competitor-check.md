## 1. 관찰 범위와 판독 기준

- 로그인하지 않은 공개 페이지와 서비스의 공식 안내만 확인했다. 가입·게시·팔로우·댓글 작성·결제·알림 수신은 실행하지 않았다. 실명·이메일·원문 전문은 이 문서에 기록하지 않는다.
- 확인 시각은 조사자가 페이지를 확인한 KST다. 게시물 옆의 시각은 별도로 “사이트 표기”라고 적으며, 서비스의 표시 시간대를 KST로 추정하지 않는다.
- 웹 도구로 URL을 직접 열고, 추가 직접 확인에는 `insane-search`의 `scripts/run -m engine "<URL>" --json-content`를 사용했다. 추출 성공은 공개 본문을 읽었다는 뜻이며 로그인 후 동작이나 화면 전체를 검증했다는 뜻은 아니다.
- **미확인**은 “없음”이 아니다. 비회원 화면에서 증거가 없거나 접근에 실패한 항목은 그대로 남긴다. 검색 결과나 다른 서비스에 등록된 소개만으로 해당 서비스의 현재 기능을 확정하지 않는다.
- K-4의 비교 항목은 ① 프로젝트에 귀속된 게시물 ② **최신순** 기본 피드 ③ 프로젝트 페이지의 시간순 게시물 목록이다. 인기·알고리즘 정렬을 알아냈다는 이유로 ②를 충족한 것으로 세지 않는다.
- **집계 기준 [제안]**: 공개 화면·공식 안내로 확인한 제공만 센다. 피드에 프로젝트와 무관한 게시물도 섞여 있고 일부 게시 유형의 연결만 확인되는 경우는 ①을 부분 확인으로 두고 보수적으로 제외한다. 미확인과 부분 확인을 미제공으로 단정하지 않는다.
